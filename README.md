### ⚡ Overview

**My Cloud** হলো একটি আধুনিক, দ্রুতগতির এবং সুরক্ষিত ক্লাউড ফাইল ম্যানেজমেন্ট প্ল্যাটফর্ম। সাধারণ ক্লাউডে ফাইল আপলোডের ক্ষেত্রে যে আকারের সীমাবদ্ধতা থাকে, তা সম্পূর্ণ দূর করার জন্য এতে সরাসরি ক্লায়েন্ট-সাইড স্ট্রিমিং প্রযুক্তি ব্যবহার করা হয়েছে। ফলে কোনো ধরণের সাইজ লিমিটেশন ছাড়াই যেকোনো ফাইল সংরক্ষণ ও ব্যবস্থাপনা করা যায়।

### 📌 Lifetime Storage Guideline

> [!IMPORTANT]
> **ফাইল আজীবন অক্ষত রাখার নিয়ম:**
> ফ্রি স্টোরেজ ক্লাস্টারে আপনার আপলোড করা ফাইলগুলো সক্রিয় ও নিরাপদ রাখতে **প্রতি ৩০ দিনে অন্তত একবার** ফাইলের লিংকে ঢুকে ফাইলটি ভিউ বা ডাউনলোড করুন। নিয়মিত ব্যবহার বজায় থাকলে ক্লাউড থেকে ফাইল কখনোই মুছে যাবে না।
